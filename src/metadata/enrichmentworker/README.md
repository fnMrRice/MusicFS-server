# 元信息任务与预览

`Service` 使用持久队列驱动现有本地 Scraper。请求包含一首或最多 64 首显式来源，以及字段、语言、实例选择与排除条件。当前本地实例不支持查询修正，非空修正明确返回 `UNSUPPORTED`；不访问外部网络。

每个目标独立执行，最多 30 秒；同一任务最多保存 32 MiB 预览和 256 个候选，每目标最多 64 个候选。后台默认一条、最多两条执行通道，插件忙时在目标期限内等待，不增加进程上限。NCM 解密器由组装层独立注入，不占播放解密通道。某目标失败不会丢弃其他目标结果。

正文经过插件与宿主两次验证，使用 `ContentService.UploadGuarded` 写入不可变媒体对象，再保存候选引用。来源文件保护保留到对象引用发布结束；数据库与公开任务描述中没有歌词正文、图片字节、原始路径或资源访问票据。取消、重启恢复和旧执行回调由持久代次隔离。重启仅重试未完成目标，已完成目标保留；旧代次不能提交结果。

搜索只生成预览。候选有效期 30 分钟，用户应用时提供当前选择修订与幂等键。在同一事务内重新检查任务状态、代次、候选有效期、来源资产版本、对象身份和选择修订，再经过真实对象文件保护提交人工选择和锁。候选的初始选择修订只是搜索快照；用户可以读取新修订后继续选择另一字段。已成功操作可以重放原结果，即使任务后来取消或候选过期；新操作不能使用失效候选。

歌词语言按来源声明处理：未知为 `und`，常见 ID3 ISO 639-2 别名规范成语言主标签，不根据正文猜测语言。指定语言时不将 `und` 当作任意语言；封面没有语言。请求若没有语言过滤，会保留所有声明语言的候选。

扫描后的歌词导入和后台自动补缺通过本包的自动任务入口执行，策略与人工锁边界见[资料补全](../../../docs/metadata/metadata.md)。
