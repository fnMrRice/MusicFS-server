# 歌词与封面补全任务

`Service` 把每次搜索保存为持久任务，按用户选择的来源、字段、语言和插件实例启动 `enrichment.Host/Session`。搜索产生预览，用户确认后才发布人工选择。扫描后自动补缺的字段范围与人工锁规则见[资料补全](../../../docs/metadata/metadata.md)。

## 任务生命周期

1. 每个目标独立执行。会话接收实例声明支持的字段和查询修正；本地提取插件对非空查询修正返回 `UNSUPPORTED`。
2. 插件与宿主分别验证正文，`ContentService.UploadGuarded` 将歌词或图片写入不可变媒体对象。来源文件保护持续到对象引用发布完成，数据库候选只保存引用。
3. 用户选用候选时提交当前选择修订和幂等键。事务内复核任务代次、有效期、来源资产版本、对象身份和选择修订，再写入选择与人工锁。重放已成功的请求返回原结果。
4. 取消或重启时按任务代次隔离迟到回调。重启仅重试未完成目标，单个来源失败时保留其他目标的结果。

## 范围与期限

| 项目 | 范围 |
| --- | --- |
| 来源与执行时间 | 每任务 1–64 个显式来源，每目标最多 30 秒 |
| 候选及预览 | 每目标最多 64 项，每任务最多 256 项、32 MiB 预览 |
| 执行通道 | 默认 1，最多 2；插件忙时在目标期限内等待 |
| 候选有效期 | 30 分钟，新操作须使用仍有效的候选 |

歌词按来源声明记录语言，常见 ID3 别名转换为主语言标签，未知语言为 `und`。指定语言时精确过滤，未指定时保留各语言候选；封面没有语言。
