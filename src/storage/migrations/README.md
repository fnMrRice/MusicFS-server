# 数据库迁移脚本

按原始版本顺序，每满 10 个迁移合并为一个 SQL 文件；最新不足 10 个的迁移继续保留独立文件。

- `010_batch_001_010.sql`：原始版本 001–010。
- `020_batch_011_020.sql`：原始版本 011–020。
- `021`–`024`：当前尚未满组的独立迁移；后续从 `025` 继续编号。

合并文件以该组最后一个版本号开头，每个原始迁移前使用独占一行的 `-- migration: 原文件名.sql` 标记。合并只调整文件组织，不修改原 SQL 或历史版本号；以后凑满 10 个时按相同格式合并，保留所有分段及顺序。

迁移加载器按分段还原原始版本，校验版本连续、无重复、SQL 非空且文件前缀与末段版本一致。执行、事务、`schema_migrations` 记录及 `before-NNN` 升级备份仍逐版本进行，已有数据库可以从组内任意旧版本继续升级。备份校验和发布清单使用原始 Schema 版本，不使用 SQL 文件数量。
