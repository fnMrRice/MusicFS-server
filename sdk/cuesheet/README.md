# CUE 解析基础

`cuesheet.Parse(text string) (Sheet, error)` 仅将已有 CUE 文本转换为导入候选。此包不读取文件、不创建资源、不操作物理光盘，也不实现导入或播放。

## 数据与时间边界

- `Files` 保存文件类型与规范化后的包内相对引用；`Tracks[].FileIndex` 引用对应文件。
- 所有时间使用每秒 75 帧的 `int64` 整数，不提前转换为毫秒或音频采样数。
- 每轨必须包含 `INDEX 01`，并可在它之前包含一个 `INDEX 00`。同一文件的索引不得倒退，各轨的 `INDEX 01` 必须严格递增；同轨 `INDEX 00` 可以等于 `INDEX 01`。
- `StartFrames` 等于本轨 `INDEX 01`；`EndFrames` 等于同文件下一轨的 `INDEX 01`，结束位置不包含在该轨中。因此下一轨 `INDEX 00` 到 `INDEX 01` 的间隙归前一轨。
- 首轨 `INDEX 01` 之前的内容不自动生成隐藏音轨。`Index00Frames` 保留原值供后续预览，宿主应向用户说明未纳入普通音轨的前导内容。
- 每个 `FILE` 有独立时间轴，末轨的 `EndFrames` 为 `nil`。必须经宿主探测实际时长后确定末轨结束，不推测时长，不跨文件连接区间。
- 作品级与音轨级 `TITLE`、`PERFORMER` 分别保存；缺省音轨字段保持空值，由调用方明确决定展示时的回退方式。

## 支持范围

输入支持 UTF-8、可选文件头 BOM、LF 或 CRLF，以及空格或制表符缩进。关键字不区分大小写；带空格的值必须用双引号括起。反斜杠按文件路径分隔符处理，不作为引号转义符。

支持 `FILE`、`TRACK nn AUDIO`、`TITLE`、`PERFORMER`、`INDEX 00` 和 `INDEX 01`。`FILE` 类型支持 `WAVE`、`AIFF`、`MP3`；例如 `.flac` 引用可使用常见的 `WAVE` 声明，真实格式仍由宿主探测，不由该声明决定。

`REM` 整行作为不影响时间轴的备注忽略；`CATALOG`、`CDTEXTFILE`、`SONGWRITER`、`ISRC` 验证单值语法后忽略，不读取任何外部 CD-TEXT 文件。以后需要这些资料时应显式扩展返回模型。

`PREGAP`、`POSTGAP`、`FLAGS`、其他索引编号、非音频轨、原始光盘数据类型以及未知指令均返回 `UNSUPPORTED_CUE`，避免静默丢弃可能影响时间轴或音频解释的语义。轨号必须在 1–99 之间且全局递增，允许跳号；同一规范化文件引用不能重复声明。

## 授权边界与限制

输入不超过 1 MiB，单行不超过 16 KiB，最多 99 个文件和 99 条音轨。位置格式为至少两位分钟、两位秒、两位帧；秒小于 60，帧小于 75，总帧数不能超过 `int64` 上限。

文件引用统一为 `/` 分隔并清理 `.`；允许仍落在包内的 `子目录/../音频.flac`。拒绝绝对路径、盘符、UNC、冒号、父目录逃逸、Windows 保留设备名和存在平台解析歧义的尾点、尾空格等名称。

**相对引用不是访问授权。** 宿主消费结果时仍须通过已授权目录解析引用，检查符号链接、大小写或路径别名，并探测文件格式和时长、校验所有区间。不得把引用拼成任意本机路径直接读取，也不得因为解析成功就表示音轨已经导入或可播放。当前解析器不提供公开 HTTP 接口。

失败返回 `*cuesheet.Error`，`Code` 为 `INVALID_CUE`、`UNSUPPORTED_CUE` 或 `LIMIT_EXCEEDED`。一基 `Line` 定位错误；文档级错误行号为 0。错误消息使用英文且不回显文件路径，失败时不返回部分解析结果。
