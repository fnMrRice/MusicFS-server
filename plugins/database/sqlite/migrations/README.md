# SQLite 插件数据库迁移

主库建表 SQL、嵌入资源和迁移加载器由 SQLite 数据库插件维护，随插件编译发布。插件在返回可用后端前完成建库和版本迁移，宿主不需要读取或执行外部建库脚本。发布工具从此目录读取插件声明的 Schema 历史，不使用宿主目录或旧路径兼容入口。

迁移文件整理遵循[工作约定](../../../../AGENTS.md)。当前加载器接受独立迁移和带分段标记的合并文件；文件前缀为最后一个版本号，每段以独占一行的 `-- migration: 原文件名.sql` 标记原始版本。

当前保留 024—027 四个独立版本，001—023 已合并为带原始分段的历史文件。027 新增本地作品包与持久幂等记录；从 026 升级会在执行前保留 `before-027` 备份。026 的作品资料及更早的插件设置、重复识别记录继续保留。

加载器校验版本连续、无重复、SQL 非空且文件前缀与末段版本一致。执行、事务、`schema_migrations` 记录及 `before-NNN` 升级备份逐版本进行，已有数据库可以从合并文件内的旧版本继续升级。备份和发布清单使用 Schema 版本，不使用 SQL 文件数量。更改合并策略时需同步核对加载器及旧库升级兼容性，不能只改文件名。
