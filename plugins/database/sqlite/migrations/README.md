# SQLite 主库迁移

SQLite 插件在打开主库时执行内嵌 SQL。每个版本独立记录在 `schema_migrations`，升级前创建对应的 `before-NNN` 备份。实例状态库由[独立目录](../state/)维护。

## 新增迁移

1. 按当前最大版本号加一，新建 `NNN_name.sql`，用 SQL 描述结构及已有数据的转换。
2. 保留最近四个版本的独立文件。较早文件并入历史批次，每段以独占一行的 `-- migration: 原文件名.sql` 保留原始版本。批次文件前缀使用末段版本号。
3. 确认版本连续、没有重复、各段 SQL 非空。[加载器](load.go)会校验这些条件，升级已有数据库时从对应版本继续执行。备份与发布清单都按数据库版本编号。
