# 重复识别与人工确认

## 网易云来源首次入库

导入或关联网易云歌单时，服务端会为首次入库的可用歌曲查找当前用户曲库中的本地文件。直接播放或下载网易云歌曲触发首次入库时也会查找。若匹配到已有录音，网易云来源成为该录音的一个版本。例如，本地已有两个已关联的版本，导入网易云收藏后可以在同一曲目下看到三个版本。关联的收藏或歌单也引用这首曲目。

系统优先比较网易云歌曲编号。如果本地文件标签中有相同编号，可以据此匹配。双方都提供时长且相差超过两秒时，仍会保留独立来源。如果本地文件没有编号，则要求曲名、专辑名、完整歌手集合都非空且一致，并且双方都提供时长、相差不超过两秒。比较名称时会统一大小写、修剪首尾空白并折叠连续空白，保留括号、标点和版本说明。歌手顺序不影响比较。

本地多个文件已归入同一录音时，视为一个候选曲目。只有匹配结果唯一才会归组。如果文件内外层标签记载了不同的网易云歌曲编号，该录音留待人工核对。来源曾被明确解除关联、存在人工排除、目标是人工锁定的独立曲目，或组内有其它网易云歌曲编号时，新来源也会独立保留。

已入库的在线来源沿用原分组。重启服务、重新导入或再次同步同一歌单都不会重新整理已有的重复曲目。

## 后台识别与人工操作

标准匹配插件通过设置页面提供自动识别开关、最低分数输入框和“立即识别”按钮。默认自动识别，最低分数为 35；标签相符但没有音频证据的候选也可以出现，必须由用户确认。分数是排序依据，不是重复概率。

Server 周期检查每个用户当前可用曲目的资产、标签、文件哈希、音频指纹绑定和人工关联修订。变化后使用插件选择的候选桶执行全库识别。一次识别覆盖全部来源，按最多 20 个比较项分批发布；这与旧单来源比较 API 的 256 来源上限及 20 条结果上限不同，不截断到曲库前 256 条。不同批次只替换明确比较的来源对，既往批次不会被后续批次覆盖。

`GET /api/v1/matching/candidates` 按分数、候选 ID 分页，返回本人当前候选及双方曲目。曲目信息附已有录音的完整成员，避免确认候选时把单一来源从原关联组中拉出。过期资产、失效证据、已排除的对和两端已有人工分配的对不会作为当前候选返回。

自动任务只产生候选，不改写录音关联、文件、播放顺序或时间轴证据。单个候选合并使用 `POST /matching/links`，取消候选使用 `/matching/exclusions`，解除来源使用 `/matching/unlinks`。所有人工修改保持全局本人 `expectedRevision`、幂等键及审计保护。

Web 曲目列表工具栏提供用户主动发起的“一键合并”，可选择以下方式，执行前展示范围并确认：

- **按分数合并**：合并当前有效且分数大于或等于所选阈值的候选，阈值为 0—100 的整数。覆盖全部候选分页；没有生成或已经失效的候选不会参与，必要时先运行“立即识别”。分数不是重复概率。
- **合并重名重作者**：直接检查本人全部来源中当前可见且可用的曲目，不依赖是否已经生成候选，也不要求时长接近。标题与完整作者集合必须非空；比较时忽略大小写、首尾空白与连续空白差异，作者顺序和重复作者不影响集合。保留标题括号、现场、混音等版本文字；缺少作者或作者列表含空项的曲目不参与。

两种方式均通过 `POST /matching/bulk-merge` 一次原子提交。满足条件的关系先构成完整连通组；同一曲目已有录音时保留该录音全部成员，包括暂时不可用的成员。多个既有录音可整体合并，明确解除的来源不作为匹配端点。连通组内任意成员之间存在人工排除，或扩展后超过 256 个成员时，整组跳过，不拆成部分提交。操作返回合并组数、参与合并的全部来源数和跳过组数；没有可合并项时保持原修订，但仍保存幂等结果。

批量合并只修改录音关联，不删除来源、改写标签或原文件，也不创建时间轴证据。合并后仍可从版本列表解除来源或拆分录音。新客户端根据 `/matching/revision` 的 `bulkMergeAvailable` 判断服务端支持情况；旧服务未声明时隐藏入口。详细请求和返回字段见[人工录音关联](../metadata/matching.md#批量合并)。

任务进度、设置和动作幂等记录保存在数据库。页面关闭或离开不停止识别；Server 重启后重新检查未完成任务，重跑已处理的分批操作是安全的。同一动作键在后续任务完成后仍重放原结果；正在运行时不同键的新动作返回 `RATE_LIMITED`。设置更改在下一次识别时生效：开启自动时由后台检查触发，关闭自动时需点击“立即识别”。关闭自动检查不会删除已有候选或人工关联。

后台检查间隔为 10 秒。识别期间目录扫描、标签或人工决定变化导致快照冲突时，开启自动识别会在下一次检查重试；关闭自动识别时由用户重新触发，均不回滚人工操作。当前只读取已经生成的摘要和指纹，不会为识别任务自动启用音频指纹提取或完整文件哈希计算。
