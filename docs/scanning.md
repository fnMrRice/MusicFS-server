# 扫描范围、排除规则与文件通知

Local Files插件提供配置说明和校验Schema；宿主加载YAML实例默认值，再合成本次请求覆盖。当前插件0.3.0、声明 `local-import-v3`。改变配置需重启服务，没有动态启停。授权根路径只在宿主配置中，API选择的是安全根ID。

```yaml
importDefaults:
  recursive: true
  maxDepth: 64
  importLyrics: false
  excludePatterns: ['**/cache', '**/*.tmp']
```

这是实例上与 `config` 同级的字段。默认递归64层、无排除；根本层文件是深度0。关闭递归时有效深度为0；重新开启且本层没给深度时恢复64，开启时显式0拒绝。每实例最多256个授权根，单次扫描总曲目上限50,000。

## 规则语义

每条规则相对所选的每一个音乐根，用 `/` 分隔、所有系统均大小写敏感。最多32条，每条UTF-8最多256字节，合计最多8KiB；规则先排序，重复拒绝。字符类、花括号、否定、绝对路径、盘符、反斜线、控制字符以及空/`.`/`..`段不接受。

| 规则 | 作用 |
| --- | --- |
| `private` | 排除根下名为private的条目；若为目录，排除整支 |
| `**/cache` | 排除任意层名为cache的条目及目录后代 |
| `*.tmp` | 仅根本层匹配扩展名tmp的条目 |
| `**/*.tmp` | 任意层匹配扩展名tmp的条目 |
| `disc/?音.wav` | disc下一层，`?`为一个Unicode字符 |
| `**` | 排除整个选中范围；不从旧库删除已存在曲目 |

`*` 和 `?` 不跨 `/`；只有独立段 `**` 可匹配零或多层。匹配目录将停止进入它，未触达的分支不能声称完成观察。规则没有“后面的包含覆盖前面的排除”顺序含义。

## 请求与既有曲目

先读 `GET /api/v1/provider-instances` 获取当前 `configuration.schemaRevision` 和 `roots`，再提交完整模式/修订/根ID及部分选项：

```json
{"mode":"full","schemaRevision":"local-import-v3","rootIds":["local"],"options":{"excludePatterns":["**/cache"]}}
```

每一层的 `excludePatterns` 都整组替换，省略继承、显式 `[]` 清除，不自动追加。`scripts/scan.ps1 -ProviderID local -ExcludePatterns '**/cache','**/*.tmp'` 可提交本次规则；传 `-ExcludePatterns @()` 清除实例继承。登录、Origin/CSRF、幂等键和等待任务由脚本处理。

有效递归、规则、根身份、插件/配置/声明版本共同进入不可变计划及摘要。同一规则集调换顺序可重放相同幂等键，改变有效规则则冲突。Host遍历、返回观测检查和数据库缺失对账使用同一个匹配器；被排除、超深或未选择根的旧记录保持原样，包括已验证摘要和人工内容。清除排除后，完整复核才可以把确实消失的同一来源标为missing。排除不是撤销读取权限，也不是删除曲库操作。

旧身份从被排除、未选根或超深位置移入本轮允许范围时，宿主也会拒绝重绑，以保护本轮范围外的旧记录。此时请显式选择同时覆盖旧、新位置的完整范围，必要时清除排除规则或提高深度，再复核；合法移动并非永久无法扫描。拒绝的整次发布不会部分改动曲库。

扫描失败/取消/根身份改变保留旧库；增量模式仍执行受控完整复核，不能从文件名或扩展名推断可解码。分页空闲5分钟内可续期，总寿命1小时，不允许无限续租。任务的有界重试和paused状态见[重试验证](validation/scan-retries.md)。

## 文件通知与周期补漏

通知调度由宿主实施，仅Local Files实例支持。它默认关闭；开启需修改实例 `config` 后重启，插件与实例本身也必须启用：

```yaml
config:
  watch:
    enabled: true
    debounceMs: 1000
    maxDelayMs: 10000
    fullRescanSeconds: 3600
  musicRoots:
    - id: local
      name: 本地音乐
      path: /music
```

`watch` 可省略，或只覆盖部分字段。`debounceMs`为100—30000毫秒；`maxDelayMs`为100—60000毫秒且不能小于去抖时间；`fullRescanSeconds`为30—86400秒。省略分别采用1000、10000、3600，显式0或null拒绝。时间是触发条件，执行仍须等待扫描队列与来源读取租约，不是完成时限。

启用后先完整复核。Windows使用目录通知，Linux使用inotify；变化合并为一次增量提示，持续事件达到最大等待时间也会提交。通知不直接更新数据库：任务仍固定当前实例的全部授权根、实例默认递归/深度/排除/歌词选项，并走正式扫描、代次和完整发布。单次手工扫描覆盖只影响该次任务，不修改监听默认范围。

每实例最多256个监听目录；每个授权根的目录注册遍历最多50,000个条目，采用每批128项读取。最多8个实际启用监听的实例。只对授权、深度内且未排除的目录分别注册非递归监听，不跟随符号链接扩展授权。每实例仅保留一个合并事件信号和一个待扫描标记；扫描运行或处于 `retry_wait` 时不会因事件洪峰新建大量任务。Windows每目录缓冲8KiB，最多2MiB/实例；Linux单实例读取缓冲32KiB。目录句柄、事件缓冲和后台循环在关闭时回收。

目录数量超限、目录不可读、平台/文件系统不支持或通知失败时，日志出现 `scan watch degraded to periodic reconciliation`，仍按周期完整复核；定期重试注册。通知队列溢出也触发复核。创建目录后会重建监听集合；注册与扫描之间仍可能有竞争，周期复核补齐丢失事件。网络文件系统的通知可靠性不作保证，尚未通过实际NAS验收。

权限、认证或来源离线使扫描进入 `paused` 时，本实例监听停止自动提交，日志为 `scan watch paused until restart`。修正依赖/权限后可手工扫描；恢复持续监听需要重启服务，不能靠新自动幂等键绕过暂停。日志只包含实例、任务和稳定错误码，不输出音乐根私有路径。
