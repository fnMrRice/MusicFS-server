# 完整处理输出缓存

S-P4-08 为当前 `mp3-128`、`gain-v1` 处理链提供私有磁盘缓存。音频仍由独立 Worker 边处理边交付；只有处理链成功结束、来源与播放尝试仍有效时，才原子发布完整结果。缓存属于可丢弃运行数据，不是永久 Media Store 对象，不修改音乐原件。

## 身份与授权

缓存键包含用户、Provider 实例、SourceTrack、SourceAsset ID 与版本、实际解密后输入 SHA256、启动时验证的 Worker/FFmpeg SHA256、插件版本、处理链版本、输出 profile、增益和起点。NCM 输入摘要来自私有解密快照，原 NCM 容器身份仍单独绑定资产 ID/版本。

同一资产的不同出处仍保留独立来源身份；不同用户、工具、增益或起点不能共用结果。公开 API 不接受缓存路径或缓存键，也没有跳过来源授权的缓存下载接口。

复用前检查实际 Provider 授权文件版本，并在同一 SQLite 事务内检查登录、资料库所有权、当前资产和活动会话/attempt。发布前也检查实际来源与当前内存 attempt，再由 SQLite 事务复核身份，防止 seek、Stop、撤销登录或资产换版后的晚结果发布。

输出文件位于 `cacheDir/playback/processed`：48 位十六进制名称的 `.part` 是临时输出，`.mp3` 是候选完整文件；只有文件同步、重命名及授权索引事务都成功后才能命中。SQLite `processed_cache` 只保存完整索引与身份，不存音频正文。私有文件权限为 0600，目录为 0700；实际 Windows ACL 仍继承配置目录的控制范围。

## 配额、取消与回收

无需新增 YAML 选项：沿用顶层 `maxCacheBytes`，输入快照、并行临时输出、完整结果和删除失败的文件共同计费。输入复制预留实际长度，旧输入有读取引用时不提前释放预算；恢复期间旧、新输入同时计费。

缓存写入在已交付的输出之后进行，保留慢消费者背压。磁盘错误、缓存满或发布复核失败只放弃缓存，不额外使已成功交付的处理播放失败。处理本身失败、取消或不完整输出不会进入完整索引。同键只允许一个缓存写入者；其他播放可正常使用既有处理并发控制，不额外启动专用填充进程。

最多 128 个完整、写入中或待清理条目，最多 8 个并发缓存写入者；数据库删除故障及零字节临时文件也受条目上限约束。达到上限时直接降级为不缓存。活动 attempt 和独立 HTTP 读取持有引用，GC 不删除仍被使用的对象。

默认空闲期限 5 分钟，完整结果硬期限 24 小时，回收周期 30 秒。释放最后引用后重新计算进程内空闲期限；新输入需要空间时优先淘汰无引用的旧输出。文件真正删除前预算不会释放；删除失败重试，不递归删除未知目录。硬期限只阻止新命中，不中断已持有引用的读取。

重启校验完整索引、长度和 SHA256，清理半成品、孤儿、损坏、超期和超配额文件；不会恢复半完成处理。运行中命中还检查普通文件、文件身份、长度与修改时间。备份不包含缓存音频；恢复数据库时删除 `processed_cache` 索引，之后按缺失/孤儿规则清理。缓存故障恢复不复活旧播放会话。

## 交付与定位

命中仍返回原有 `deliveryMode=processed`、`seekMode=timeRestart` 与起点，HTTP 保持 `Accept-Ranges: none`，不返回缓存长度、ETag 或假 206。新的时间定位产生新 attempt，并按新起点查找独立结果。客户端仍须清空旧缓冲；本步骤没有增加通用 MP3 字节定位或跨源时间证据。

## 验证

单元测试位于 `tests/unit/processedcache`，覆盖身份隔离、引用 GC、压力淘汰、共享预算、取消、重启校验、损坏文件、删除失败保留额度及连续零字节清理故障的有界准入。

`tests/integration/playback/cache_repository_test.go` 使用真实扫描资产与 SQLite，检查跨用户、撤销登录、停止、attempt 更新、实际重扫换资产的复用/发布拒绝，以及旧输入读取结束前不释放预算。测试用的合成缓存记录只验证存储授权，不表示执行过音频处理。

`cache_audio_test.go` 使用合成 WAV、真实独立 Worker 和 FFmpeg。首轮完整处理后暂时移走测试自行构建的 Worker，复用请求仍逐字节一致，证明没有再次处理；验证 4 秒定位分键、增益隔离、重启复用、HTTP Range 不伪造、原件摘要不变、实际原件变化拒绝命中、配额满仍可播放及取消不留下半成品。测试不会移动系统工具或私人音乐。

2026-10-10 Windows FFmpeg 6.1.1 真实音频定向验证 6.812 s，SQLite/旧读取配额定向验证 2.681 s 通过。
