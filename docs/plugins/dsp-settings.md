# DSP 配置与输入输出协商

Web 的 DSP 和输出布局在浏览器本地实时执行。服务端效果和声道插件默认由 `audioDSP.enabled=false`、`audioChannels.enabled=false` 禁用，以下接口与历史配置保留；禁用时效果目录为空，布局只接受不启用转换的 stereo 占位值，播放实际输出按来源选择。旧个人或全局布局不影响客户端模式，也不会绕过部署禁用标记。执行归属见 [Web 本地 DSP](../playback/local-dsp.md)。

服务端设置允许每个用户保存个人覆盖，管理员可设置全局默认。全局是默认值，不与个人链串联。未保存个人配置或选择继承全局时，下一次播放读取最新全局设置；个人覆盖后，全局变化不改写个人链。未保存全局设置时沿用部署 YAML 的 `audioDSP`、`audioChannels`。以下效果编辑行为要求部署显式启用服务端音效。

同一效果可添加多次；可以增删节点、上下移动、修改插件声明的数值参数、选择 stereo / 5.1 / 7.1 输出。每个节点显示输入与输出，声道转换可在链中移动。保存前须通过服务端整链校验：节点版本、参数范围、相邻格式、是否可继续 DSP 和最终编码布局全部兼容。前端不能安装外部程序或指定可执行路径；外部节点只能使用管理员已经登记的配置。

## 生效与持久化

设置保存在已有 `plugin_settings` 数据表，无需新增表。个人项以用户 ID 与 `musicfs.dsp.pipeline` 隔离；全局使用宿主专用所有者与 `musicfs.dsp.global`。所有者只取自认证会话；全局接口额外要求 `admin`。读取个人配置可见其生效的全局默认，但不能改写全局。

可移植备份恢复会停用音频插件并清除恢复副本中的个人、全局 DSP 设置，避免恢复到新机器后引用缺失的处理器或外部节点；其他插件偏好和原备份不受影响。仅缓冲区不同的空链立体声设置不强制转码，无可用处理器时仍可走兼容原流；非空效果链、环绕声、用户增益或显式强制处理仍要求可用处理器。

保存使用修订比较，旧修订返回 `CONFLICT`；失败不修改生效值。最后一次相同幂等键、原修订和内容的重试返回已保存结果，后续变更不会被旧请求覆盖。选择继承保存一个继承标记，而非复制全局参数。前端保留冲突或网络失败的草稿，只有用户明确保存才替换配置。

保存仅影响之后创建的播放会话，不改当前歌曲或中途跳转。会话固定一份链、输出布局和缓冲区快照；缓存、时间轴证据和恢复身份包含这些配置。不同用户共享音频实例的并发配额与启停门禁，配置视图不会绕过限流。部署或插件代次变化仍触发既有恢复边界。

## 缓冲区

`bufferFrames` 为实际每次送入 DSP 的采样帧数，默认 4096，内置链允许 64–16384 的整数，最后一块可不足此值。它不是网络缓存，也不直接决定音频质量。48 kHz 下 64 帧约 1.33 ms，4096 帧约 85.33 ms，16384 帧约 341.33 ms；这些只是一个处理块承载的音频时长，不是端到端延迟承诺。较小块增加调用频率，较大块增加单次处理量。

外部 MFD1 v1 仍最多 4096 帧并仅支持双声道，较大缓冲区明确拒绝，不隐式拆分第三方节点。内置均衡、压缩、混响与声道转换验证了不同分块的输出一致性；缓冲区仍计入处理身份，避免假设任意外部算法都与分块无关。

## 插件输入输出

`audio.Node` 原入口保持兼容，新节点可实现 `IODescriber.DescribeIO(input Format)` 和 `IOConfigurer.ConfigureIO(input Format)`。返回 `audio.Output{Format, CanContinueDSP}`，宿主逐节点协商并核验实际音频块。`CanContinueDSP=false` 表示可以交给最终消费者，但不能再接下一个 DSP；该标记属于插件声明，不能由页面随意覆盖。

当前音频块为 48 kHz 交错 f32le PCM，允许 mono、stereo、5.1、7.1 布局转换，不允许改变帧数、时间轴或追加曲尾。新内置节点都输出可继续 DSP 的 PCM；最终 MP3 / Opus 编码在链后完成，压缩字节不能当作 PCM 串入 DSP。旧节点兼容为同格式输出；旧外部协议的格式限制保持独立。

播放入口先将源布局自动适配到所选编码布局，再执行用户增益与可编辑链。因此中途转成其他布局后，需要在链末转回所选输出；保存时显示不匹配错误，不自动插入不可见节点。参数和能力声明由内置插件目录提供。

## API

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/dsp/settings` | 当前用户设置、全局默认、是否继承、节点目录与可用输出 |
| `PUT /api/v1/dsp/settings` | 保存个人覆盖，或以 `inheritGlobal=true` 恢复继承 |
| `GET /api/v1/dsp/settings/global` | 管理员读取全局配置和部署默认 |
| `PUT /api/v1/dsp/settings/global` | 管理员保存全局默认 |
| `POST /api/v1/dsp/settings/validate` | 无副作用校验，返回逐节点输入输出预览 |

写请求需要同源与 CSRF 校验；保存另需 `Idempotency-Key`、`expectedRevision` 和 `schemaRevision=dsp-settings-v1`。保存覆盖时提供 `settings={chain,outputLayout,bufferFrames}`；继承时只提供 `inheritGlobal=true`，不能同时传 `settings`。精确 Schema 由 [HTTP 契约](../contracts/http.schema.json) 与 [OpenAPI](../contracts/openapi.yaml) 管理。

音频实例不可用时页面仍能读取设置，保存和预览返回不可用；当前实例只接受其实际探测支持的输出编码。真实 5.1/7.1 扬声器输出还取决于客户端、操作系统与设备。
