# 网络来源按需播放

来源插件通过握手声明 `sourceType=local|network`。宿主只按已校验的声明选择播放输入：`local` 沿用本地文件及现有处理流程，`network` 使用按需读取；缺少有效来源类型时拒绝播放，不根据平台名称、来源 ID、文件路径或 URL 猜测。

## 元数据与会话

`POST /api/v1/online-instances/{id}/tracks/{externalId}/resolve` 在实例声明 `stream.resolve` 时获取曲目元数据，创建或更新稳定的 `SourceTrack` 并返回该曲目。此操作不打开音频响应、不下载、不计算哈希。对应资产标为 `unversioned`，文件大小、哈希及字节证据均未知；`metadataDigest` 不用作音频版本。

客户端再调用既有播放会话接口。创建网络会话时，宿主通过插件 `DescribeAudio` 查询媒体类型、容器和编码描述，用于选择客户端支持的格式；该方法只查询平台资料或播放描述，不向 CDN 发送 HEAD/GET，也不读取媒体。具体格式由插件声明，不由宿主硬编码平台与格式的关系。

客户端 GET 会话返回的 `streamUrl` 时，宿主再次校验播放授权和表示身份。命中可复用的完整版本后读取服务端文件，未命中时通过插件打开受控媒体流。每块至多 64 KiB，每次最多 256 MiB。会话结束、取消请求或来源授权撤销会关闭正在读取的响应。

## 下载版本与容量

在「设置 → 插件管理」打开对应在线来源的配置。网易云的播放音质默认为「极高」，可选标准、极高、无损、高解析度无损、高清臻音、超清母带、沉浸环绕声。下载使用同一次播放实际获得的版本，平台降档时按返回音质记录。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| `cacheLimitMiB` | 1024 MiB | 同一 MusicFS 用户、同一插件的实例共用容量。服务端每天按本地日期清理一次，从最早下载的版本开始回收到上限，跳过使用中的文件。重启时补做当天清理。设为 0 后，新的播放停止复用和保留下载。 |
| `streamWhileDownloading` | 开启 | 收到媒体数据后即可播放。关闭时等本次下载完整后开始播放。容量为 0 时使用临时文件，播放请求结束后删除。 |

曲库来源通过 `downloaded` 和 `downloadVersions` 提供服务端已完成的下载。每个版本包含版本编号、实际音质、格式、大小及下载时间。取消、超时或接收不完整的下载不会标记完成。同一来源的不同音质、媒体版本可以并存。

在曲目的来源列表展开「已下载」后，可按实际音质和下载时间找到要移除的版本，逐个删除。删除最后一个版本后，来源会清除已下载标记。之后播放这个音质时，可以按缓存设置重新下载。客户端调用 `DELETE /api/v1/source-tracks/{sourceId}/downloads/{versionId}` 删除当前用户的指定版本，成功返回 204。

网易云按平台账号和媒体版本复用缓存，同一账号重新登录后仍需通过曲目授权检查。对于 Bilibili 等来源，CDN 提供强 ETag 时可在取得响应头后复用对应版本。如果平台没有提供可靠版本，服务端读取完整音轨并按实际内容去重。

## 定位与处理边界

当前网络输入使用原始编码代理，不预先固定全部字节，因此 `seekMode=none`，不返回 ETag、不支持跨请求字节拼接。HEAD 不打开上游；无 Range 或 `Range: bytes=0-` 返回从零开始的顺序响应，其他 Range 或 If-Range 请求要求重新播放。同一 attempt 只允许打开一次 GET 响应；失败重播需要新会话。初始 `resumeDecision=continue` 表示允许开始本次播放，不表示可复用旧字节偏移。

网络流尚未接入服务端转码、增益和 DSP 处理；强制服务端处理或客户端不支持插件描述的格式时返回 `UNSUPPORTED`。客户端 DSP 可沿用浏览器路径。没有固定音频版本或时间轴证据时，同源恢复和定位返回 `RESTART_REQUIRED`，不会暗中重开上游并拼接旧表示。

## 授权与验证范围

网易云使用当前平台账号播放完整授权曲目，按账号与曲目的实际授权返回音质。Bilibili 使用匿名公开音轨。平台账号变化、到期或退出会中止已打开的相关响应。QQ 和 Apple Music 尚未声明 `stream.resolve`。

已有自动化验证覆盖：元数据与会话创建不读取媒体、声明驱动的来源及格式分流、首段到达即转发、完整 EOF 保留会话、浏览器取消与来源撤销关闭上游、HEAD/Range、跨用户 SDK 请求、CSRF、未登录及禁用能力。Bilibili 真实浏览器音频播放和平台长期可用性仍需独立在线验收，不能用合成音频测试替代。
