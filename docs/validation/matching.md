前一步 S-P5-03 已完成全量检查；本步按变更覆盖完整存储/HTTP/E2E 和候选服务包。真实 E2E 包含既有扫描、原流、处理流、NCM、指纹和本步人工关联，不因指纹开关或缺候选影响普通播放。

14份项目数学合成音频的实际指纹向量验证不同编码/码率、前导静音、局部范围和不同混音；纯音低信息碰撞被拒绝，近似演奏仍可能成为待确认候选。样本与来源放在 `tests/testdata/identification`，没有私人音乐或私人指纹。指标与门槛没有准确率/概率承诺，不据相似分数自动合并。

真实 SQLite 验证当前完整 SHA-512 及文件长度一致才进入最强候选；Provider 申报不能替代。候选快照绑定资产、元数据、所有当前指纹索引和人工修订，旧快照不能覆盖后来决定。比较池、每源索引、总位比较次数、返回数、并发和期限均有上限；默认最多比较256个本人来源，不宣称完整检索任意规模音乐库。

人工关联、解除、拆分和排除覆盖预期修订竞争、幂等重放、冲突键、跨用户隔离、成员上限、排除优先、重启保留和逐来源原目标审计。重放旧关联操作不会重新执行已被解除的关联。真实服务用两份独立 WAV 计算完整摘要形成100分待确认候选，再完成整个人工链路、重启、范围播放与停止；原件摘要不变。

测试没有新增 Web 管理界面、自动关联、远程检索、跨源时间映射或歌单隐藏传播。审计中的原目标/新目标是 P7 可逆意图处理的输入，不能据此宣称 P7 已实现。物理 NAS、其他平台和人工听音仍单独验收。
