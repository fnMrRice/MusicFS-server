# S-P8-05：完整安装备份与恢复验证

日期：2026-10-10。实现说明见[完整备份](../backup.md)。此次测试均用独立临时目录、项目合成音乐及人工生成歌词，不备份用户真实音乐库。

- Windows 真 SQLite/文件 race：8.320秒。覆盖人工选择与锁、歌词文件、插件状态、管理员令牌不入包、旧浏览器会话撤销、显式缺失文件、内容损坏、路径注入、目标已存在、备份与目标嵌套、配置外部修改。
- Windows 真实 CLI/Server race：11.573秒。运行中持有数据锁导致备份命令拒绝；停止后创建/校验/恢复到新目录；同一程序重新启动恢复库，历史歌词可读、插件保持关闭、原 WAV 字节不变；不完整恢复标记阻止启动。
- Linux WSL2原生vet通过；备份集成race6.103秒、真实CLI/Server恢复race25.099秒通过。没有物理NAS、ARM、跨系统恢复或掉电实机证据。
- 追加校验：即使重新计算清单SHA-256，也拒绝省略数据库实际引用的媒体；拒绝插件状态符号链接。Windows备份集成race15.376秒通过。
- 在包含P7迁移019的联合冻结快照上，Linux再次通过vet、备份集成race11.500秒、真实CLI/Server恢复41.64秒；覆盖恢复屏障在复制前同步父目录的修正。

- 迁移020及持久处理缓存接入后的独立冻结复验：Windows备份集成race28.552秒、实际CLI/Server18.772秒；Linux对应16.179秒、33.861秒，双平台vet均通过。新增真实SQLite过期缓存索引与文件夹具，恢复后索引清空、目标缓存为空、原安装缓存内容不变。
