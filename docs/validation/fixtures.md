# 测试夹具

音频夹具为项目生成的数学正弦波，采用 CC0-1.0；不包含私人音乐、第三方录音或真实凭据。输入摘要、长度、探测结果和生成工具版本见 `tests/testdata/audio/manifest.json`。验证方法见[复验指南](verification.md)。

## 音频生成

```text
python scripts/generate-fixtures.py --ffmpeg <ffmpeg-executable> --ffprobe <ffprobe-executable>
go test -mod=readonly ./tests/contract/api
```

生成器使用 Python 标准库与本机 FFmpeg/ffprobe，工具二进制不随夹具提交。WAV 为 48 kHz、双声道、16-bit little-endian PCM；峰值 0.125（约 -18.06 dBFS），正弦稳态 RMS 约 -21.07 dBFS，边界使用 10 ms 平滑。人工听音先调低音量。

| 文件 | 内容与用途 |
| --- | --- |
| `markers.wav` | 6 秒；0–2 秒左声道 220 Hz，2–4 秒右声道 440 Hz，4–6 秒双声道 660 Hz |
| `中文 空格曲目.wav` | 相同时间/声道分段，频率 330/660/990 Hz；验证路径和切歌辨识 |
| `silence-prefix.wav` | 前 2 秒静音，再接 `markers.wav`；验证非零位置与前导静音 |
| `processing.aiff` | 24-bit big-endian AIFF；处理路径候选，浏览器能否直放须实测 |
| `lossless.flac` | 6 秒 FLAC；无标签输入与无损内容探测 |
| `vbr-untagged.mp3` | 带前导静音的 libmp3lame VBR q4；无 ID3 音乐标签，不能把平均码率当 CBR |
| `corrupt.wav` | 错误 RIFF 长度及非法 chunk；应拒绝作为合法 PCM |
| `empty.wav` | 零字节；不能伪造时长或成功播放计划 |

合法夹具由 ffprobe 检查格式、采样率和声道，测试核对 SHA-512；WAV 另核对频率、声道、静音和峰值。更换编码器后重新生成并复核 manifest，不假设有损输出跨版本字节相同。

指纹变体位于 `tests/testdata/identification`，覆盖编码、码率、静音、局部片段和混音。纯音碰撞和近似演奏可产生反例；它们用于边界测试，不证明真实音乐匹配准确率。

## 平台响应夹具

合成上游用于验证适配器与宿主隔离，真实 Worker/HTTP 测试也不能因此称为平台实测。网易云、QQ 音乐、Apple Music 的业务夹具遵循当前登录前置，不能继续把匿名查询成功作为服务入口预期；Bilibili 设计中的公开匿名能力另行划分。

| 场景 | 夹具应保留的边界 |
| --- | --- |
| 资料映射 | 字符串大整数 ID；null、0、空串及缺失字段；试听、地区和权限分别表示 |
| 分页与同步 | 页间增删、重复页、循环 next、顺序改变、重复曲目、半途失败、无强快照版本和迟到任务 |
| 账号与缓存 | 不同用户/实例/账号/登录代次；未登录、未校验、过期、退出、401/403 与限流，不得跨账号复用 |
| 推荐 | 公共/个性化范围、原顺序、部分失败、stale 和真实分页语义；推荐消失不删除已导入歌单 |
| 音频交付 | `example.invalid` 假 URL、过期时间与假私密头；本地合成音频服务测试 Range、重定向、编码改变和取消 |

录制响应先在本机按白名单脱敏：替换账号、昵称、私人歌单、文本及 ID，删除 Cookie、Authorization、签名、设备标识、真实媒体 URL 与私人内容。保留字段结构、类型、缺失值和错误码，不把限流、试听或拒绝改为完整成功。

每个样例标注 `synthetic` 或 `captured-sanitized`、平台、参考版本、采集时间及授权类别；不记录可识别真实账号的信息。音频使用合成素材或明确可分发样本，不向外部服务上传私人音频或指纹。

## 验收记录字段

复验时至少填写以下字段；未执行项保持未关闭，结果归入[待验清单](README.md)对应项目。

| 类别 | 必填内容 |
| --- | --- |
| 对象 | 提交/制品摘要、Server/SDK/插件/Web 版本、输入摘要与许可 |
| 环境 | OS/架构、数据文件系统、工具版本；播放还需浏览器、profile 与输出设备 |
| 方法 | 实际命令或操作、合成/真实上游、工具解码/人工听音的区分 |
| 结果 | 通过/失败/未执行、证据路径、跳过原因、测量误差与剩余限制 |
| 收尾 | 输入前后摘要、进程/句柄/请求回收、完整缓存和未完成输出的区别 |

`canPlayType`、扩展名、HTTP 200、播放时间增长或 ffprobe 成功均不能单独证明浏览器实际有声播放。
