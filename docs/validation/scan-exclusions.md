# S-P2扫描排除规则验证

日期：2026-10-10。Local Files版本0.3.0、声明 `local-import-v3`；实现与语法见[扫描范围](../scanning.md)。规则使用既有依赖，不修改go.mod/go.sum，不涉及动态插件启停或Web页面。

## 实际范围

- 单元覆盖根相对分段glob、独立 `**` 的零/多层、目录后代、大小写、Unicode单字符、边界/重复/非法路径、规则排序摘要、显式清除和深拷贝。
- 配置真实解析YAML并验证类型/未知/null/越界拒绝、配置快照修改不影响当前规则。插件提供数组说明与约束，宿主执行Schema和额外路径语义检查。
- 真SQLite验证排除范围的旧资产及已验证摘要保持不变；同轮非排除缺失仍正确失效；伪造被排除观察不能部分发布；移除规则后复核同一来源ID。
- 独立审查发现仅检查新观察路径不足以保护旧身份；现在命中旧ExternalID时也检查旧根/路径是否在本轮范围。伪造允许路径以重绑被排除、超深或未选根的旧曲目一律拒绝，先前同事务的新观察也回滚；来源位置、资产、已验证证据和曲库修订均保持原值。
- 正式Worker验证cursor仍绑定完整scope，保持同task/digest但更换排除规则也拒绝；错误请求不破坏原cursor。
- 正式YAML Server/Local Worker端到端：实例默认过滤、请求 `[]` 恢复全范围、删除排除文件后旧条目保留、规则重排同键重放/换规则冲突、非法HTTP请求、重启后清除规则确认缺失、稳定来源ID和剩余原文件逐字节不变。
