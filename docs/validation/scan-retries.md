# S-P1-06 扫描任务的持久有限重试

本增量只处理通用 `jobs` 队列中的完整/增量扫描，不把相同规则套到摘要、指纹、刮削、远端同步或写回的独立状态机。扫描重试沿用原 owner、Provider、目录权限、规范化计划和幂等操作，不能扩大来源范围。

## 状态与次数

- `queued`：尚未执行，`attemptCount=0`，两个尝试时间为空。
- `running`：领取时在事务中增加执行次数、分配新的 Provider 代次，并记录 `lastAttemptAt`。
- `retry_wait`：保留最后错误和已观测数量，记录唯一的 `nextAttemptAt`；它仍是活动任务，相同计划的新请求也合并，不能刷新次数或时间。
- `paused`：需要处理凭据、权限或离线原因，调度器不自动恢复。相同幂等键仍返回原暂停结果；管理员处理原因后可显式提交新操作。
- `succeeded` / `failed` / `cancelled`：终态。成功才清除错误、设置完整标记和成功时间。

每个逻辑任务最多执行三次，`maxAttempts=3`。`attemptCount` 是已经领取的总次数，`retryCount=max(0,attemptCount-1)` 是已经开始的额外次数，不把等待重试本身算作一次执行。重试运行中仍可看到前一次错误；全部公开时间统一为 UTC。

## 重试边界

只有宿主显式标注可重试、且错误码为 `TEMPORARY_FAILURE` 或 `RATE_LIMITED` 的失败才进入重试。插件 RPC 的结构化 `retryable` 与等待信息可触发此判断；插件原始消息不进入公开任务。普通 Go/存储错误、协议不完整、资源变化、不支持的行为和授权失败不会被“临时失败”展示码隐式转换成自动重试。

第一次退避为 1 秒，第二次为 2 秒，各增加 0–25% 抖动。有效的 `retryAfterMs` 向上取整为秒，并作为最短等待；最终等待最多 5 分钟。负值或超过 5 分钟的插件等待要求不生成无限定时器，任务暂停，公开错误中的非法等待值清空。`AUTH_REQUIRED`、`ACCESS_DENIED`、`SOURCE_OFFLINE` 直接暂停；取消直接结束。

等待任务不占用 Provider 执行租约，也不让单个慢来源阻塞其他可执行扫描。到期领取重新取得代次，旧执行者的发布和完成均被事务校验拒绝。每次执行仍须完整成功发布选定范围；失败不会发布半页目录或把未扫描范围标为缺失。

## 重启与存储故障

迁移 `021_scan_retry.sql` 增加次数、最大次数及尝试时间。活动计划的唯一索引与队列容量包含 `retry_wait`；计划与幂等请求摘要仍按既有规则验证。

启动时，残留 `running` 视为一次已经消耗的执行，清理旧执行租约和代次，以“扫描被中断”记录有限退避；第三次中断直接失败。原本已在等待的任务不重新抽取抖动或修改时间，多次重启不能补充预算。恢复不会重解释旧扫描计划。

处理函数返回后，任务结果持久化独立使用至多 5 秒、最多三次写入尝试。提交结果不明确时先读取已保存状态，避免重复完成。若仍无法记录，调度器停止领取后续任务，输出不含底层路径/凭据的英文日志；活动任务查询与新提交返回明确的安全错误。服务重启后的恢复继续使用已经消耗的次数，不能把结果存储失败变成无限扫描。

## 验证入口

- `tests/unit/jobs`：允许清单、次数耗尽、等待上下界、错误脱敏，以及结果写入短暂失败、持续失败和提交结果不明确。
- `tests/integration/library/scan_failure_test.go`：独立测试 Worker 通过正式 stdio RPC 返回显式重试标记、毫秒等待和敏感原始消息，或直接断开；经公开 `Library.Scan/Job/List` 与 SQLite 核验状态、期限、脱敏和旧库保留，不为测试导出内部函数。
- `tests/integration/storage/scan_retry_test.go`：真实 SQLite 关闭重开、持久期限不变、相同计划合并、三次崩溃上限、代次拒绝、暂停与显式新操作、退避期间其他 Provider 继续执行；正常退出用独立完成上下文保存取消，重启不复活任务。
- `tests/contract/api/scan_retry_test.go` 与样本：公开状态/次数/UTC 时间、请求编号仅在响应填充、所有者隔离、Provider 状态和幂等预算一致。

既有扫描幂等、范围计划、自动补全发件箱测试已同步恢复等待语义。`scripts/scan.ps1` 把 `retry_wait` 视为仍在等待，遇到 `paused` 停止并返回失败状态；不会自动生成新幂等键绕过暂停。当前没有任务恢复按钮或改变重试预算的配置项。
