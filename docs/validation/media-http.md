# S-P6-01 媒体 HTTP 与服务验收

本记录覆盖歌词/封面内容基础接口，测试使用仓库合成 `markers.wav`、测试内生成的中文 LRC 和 2×2 PNG，不使用私人音乐、真实歌词或远端资源。

## Windows 定向验证

2026-10-10 使用本次已提交的依赖版本执行 `go test -mod=readonly`，未改依赖；Go 和依赖详情见[依赖记录](../dependencies.md)。需要本地监听、插件子进程及 Windows 原子文件发布的测试在授权环境中运行，TEMP/TMP 指向仓库忽略的独立验证目录。

- `tests/contract/api` 的媒体 HTTP、上传预算/期限，以及全部模型编译、样本和 OpenAPI 引用检查：首次通过 5.790 秒；补歌词 `und` 规范响应与空值/`UND` 幂等检查后，最终通过 3.784 秒。
- `TestMediaActualServerPreviewSelectionRestartAndPlayback`：4.32 秒通过，包总计 5.461 秒。

真实 HTTP 回归覆盖上传的会话、CSRF、Origin、所有者隔离，拒绝伪造来源/路径/URL、重复 query、空正文、错误 MIME、损坏图片和尺寸超限。合法中文 LRC 超过普通 64 KiB 控制预算仍可上传；普通控制预算不被放宽。独立传输测试检查声明长度与分块上传的 8 MiB 上限、30 秒读取/写入期限、父期限不被延长及连接 deadline 清理。

实际 SQLite 与文件检查覆盖上传只保存预览、同键重放与异内容冲突、按当前修订选用并加锁、独立解锁保留内容、封面/歌词槽位独立。损坏的新预览不能替换原有选择；选中对象后来丢失会变为 unavailable，保留人工锁。旧预览仍须授权并可读取。

独立 YAML 服务在未启用指纹和处理插件时完成 LRC/PNG 上传、预览、人工选用与解锁；关停并重新启动后，正文描述、选择、锁与上传幂等仍在。原始 WAV 的 Range 播放和停止通过，内容操作前后源字节 SHA-256 相同。测试随后主动改动原 WAV 并重扫：来源编号保持，资产变代，旧绑定 stale/current=false 且锁保留，旧正文仍可读，新选用旧资产返回 409。

## 范围

以上是 Windows 自动化接口和服务验证，不是浏览器歌词编辑、人工听音、Scraper 自动补缺、写回、备份或 GC 验收。存储发布阶段恢复和并发事务另由 MediaStore/SQLite 测试覆盖；Linux 与最终完整回归由对应统一验收记录补充，不从本机结果推断。
