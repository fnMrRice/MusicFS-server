## 平台账号与在线业务

登录控制面已接入，真实账号验收尚未完成。网易云、QQ 音乐、Apple Music 的业务入口均要求已校验账号；旧匿名请求成功不能作为当前链路的验收证据。详情见[平台登录](../providers/platform-login.md)。

- [ ] 三个平台分别完成真实用户授权、拒绝/取消、风控失败、账号资料读取、重启后校验、退出和过期后重新授权。二维码创建成功不等于登录成功；Apple 还需实际开发者配置、网页来源及 MusicKit 授权弹窗验证。
- [ ] 用两个授权账号验证用户、实例、账号和登录代次隔离；退出或认证失效后取消在途请求、拒绝旧缓存/游标，重启恢复的 `unverified` 状态不能执行业务。头像与账号显示信息分别核对真实响应。
- [ ] 对各平台已声明的查询、推荐与歌单能力执行当前账号链路实测，覆盖连续分页、限流恢复、网络失败、真实远端增删和保守移除。个性化推荐、私人歌单与地区/订阅限制分别验证，不能由公开资料或合成响应推断。
- [ ] 凭据续期能力仍需按平台实现并实测；当前过期处理为重新授权。验证退出的实际范围，不承诺注销平台所有设备或撤销上游令牌。
- [ ] 授权整曲交付尚未实现。接入后逐平台核验试听/完整内容、地域与订阅权限、短期资源到期、Range、定位、取消与受控输入，Apple 目录或 MusicKit 播放不等于 Server 获得裸流能力。
- [ ] 修正并复验遗留公网入口 `tests/e2e/online_live_test.go`：它仍预期未登录业务查询成功，与当前登录前置冲突。不能使用 `MUSICFS_ONLINE_LIVE=1` 的旧断言证明当前平台能力。

## 音频、浏览器与客户端

- [ ] 原流、处理流和 NCM 在真实输出设备上人工听音，核对曲目、左右声道、音量、位置标记和连续切歌。HTTP 成功、时间增长和非零 PCM 均不能关闭此项。
- [ ] Linux 浏览器、Firefox、Safari 及其他拟支持浏览器/profile 分别验证实际解码、首声、暂停/恢复、快速定位、切歌、停止和授权失效。新 DSP 链与当前安装制品也需独立浏览器联调。
- [ ] 更多格式、声道布局和 NCM 客户端封装变体分别验证。现有抽样不覆盖整个真实音乐库，也不构成全格式兼容结论。
- [ ] 每个新增处理 profile 明确定位容差并实测前导静音、编码延迟和输出起点；当前 MP3 场景使用 100 ms 容差，不承诺采样级定位。跨源续播仍需绑定双方资产版本的独立时间轴证据。
- [ ] 桌面 Client 实现后联合验证原生能力协商、多客户端启动/退出、崩溃租约回收、独立 Server 保持运行、remote 不启动本机进程及可恢复升级；Server 的租约测试不能替代桌面实现。

## 文件系统、扫描与内容

- [ ] 实体 NAS 的失挂/重挂、慢存储、部分权限、根身份改变、同尺寸覆盖、挂载替换和通知丢失；失败或不完整扫描保留旧曲库，不能发布成功空库。挂载 NAS 与直连 NFS/SMB 分别验收。
- [ ] 目标文件系统上的稳定读取保护、SQLite 锁与发布同步，以及 Linux 挂载置换、Windows junction 置换竞争；本地 NTFS 或 WSL `/tmp` 结果不能代替完整文件系统矩阵。
- [ ] Linux 实机验证当前不限递归深度、隐藏条目与 `.nomedia` 过滤、目录通知和范围对账；该增量现有记录只有 Windows 运行与 Linux 交叉编译。
- [ ] 大库全量播放/摘要、长时间扫描及实际一小时总寿命边界；现有真实库仅完成有限抽样，快照总寿命主要以缩短期限用例验证。
- [ ] 排查真实 Worker 分页用例曾出现、尚未复现的一次 10 秒请求超时；后续重跑成功未解释根因，复现时保留请求阶段、进程状态和资源负载。
- [ ] 以授权真实音乐评估匹配候选准确性，覆盖不同编码、剪辑、混音和近似演奏。合成纯音存在碰撞，分数不能当成自动录音关联或时间轴证据。
- [ ] 目标介质的断电恢复与持久性演练。进程故障注入不能证明硬件掉电保证；写回仍仅限已声明的 Windows 本地 NTFS 普通 FLAC，定制 SACL 等元数据语义尚未验证，不扩大到 Linux/NAS。
- [ ] 远端 Scraper 需独立实现与验收，验证查询修正、候选预览、人工锁、内容授权和失败保旧，不以在线 Provider 的账号或本地 Scraper 测试代替。

## 插件、部署与资源

- [ ] Linux 原生运行当前 SDK 拆分、全量统一插件、外部 SQLite/DSP、基础设施管理展示与停用重启语义的组合版本。早期 Linux 基线和新版本交叉构建不能代替本项。
- [ ] ARM64、macOS、其他 Linux 发行版分别完成构建与实际运行；C++/第三方插件按其目标协议、平台、版本与故障路径独立验证。
- [ ] 当前双程序制品在另一台干净物理机器完成安装、工具依赖配置、扫描、原流/NCM/处理播放、备份恢复和生命周期退出。冻结同一提交、SDK、插件与 Web 版本后复验，不复用旧八程序安装结论。
- [ ] Docker/Compose 实际运行，验证受限账号、只读音乐挂载、持久目录、健康检查和退出；真实 Nginx/TLS 代理加远程浏览器验证 Cookie、Origin/首帧 CSRF、WS 升级/心跳/重连、HTTP Range、流式交付与撤销。
- [ ] 当前插件/SDK 的线上升级和恢复演练；完整备份按支持的 OS/架构/Schema 恢复，跨系统搬迁或任意版本降级需另定方案与验证。备份包含平台凭据密文及同目录保护密钥，须按凭据级别保护；恢复后重新校验平台会话，失效时重新授权。
- [ ] 长时间及生产规模负载、Linux 同负载资源曲线、慢消费者和并行后台任务。Windows 短测仍有 65 个高于初始值的句柄未逐项归因，短时平台期不能证明无泄漏。
- [ ] 完整处理缓存的真实闲置回收、24 小时上限、重启与配额压力；已有短测区分了完整缓存与取消后的 `.part`，没有完成长期观察。

## 设计能力的验收门槛

下列内容仍属设计，完成实现后再验收；详见 [NAS / Bilibili 计划](../design/nas-bilibili.md)。

- [ ] NFS、SMB 各自完成真实共享的扫描、元数据、播放、定位、离线恢复及根身份变化；协议版本、安全选项和权限分别验证。
- [ ] Bilibili 分别完成免登录视频音轨、公开收藏夹、多 P 展开、音频区曲目和独立歌单；可选私有功能另验账号隔离。分页不完整、转私有或账号失效不能清空已发布快照。
- [ ] NAS/在线资源 SDK、来源资产建档和二进制通道补齐后，验证固定字节版本、受控网络、取消和过期恢复；播放 URL、标题、分 P 序号或元数据摘要不能充当资产版本证据。

关闭项目时，附可复核的提交/制品、环境、执行方式及结果；跳过、交叉编译、合成响应和工具解码不能冒充实机、授权账号或人工听音。通过后可从本页删除，失败及仍受限制的范围继续保留。
