# 服务端待验收清单

本页列出仍需实机、真实账号或长时间运行才能确认的范围。复验时记录代码或制品版本、操作系统、工具版本、输入与实际结果。[复验方法](verification.md) · [测试夹具](fixtures.md)

## 在线来源与资料

- [ ] 使用授权账号逐平台验证网易云音乐、QQ 音乐和 Apple Music 的登录、拒绝、取消、过期重授权、重启校验及退出。以两个账号核对实例隔离、在途请求和旧缓存。Apple 另需真实 MusicKit 配置和网页授权。
- [ ] 逐项验证插件声明的搜索、推荐与歌单能力，覆盖多页数据、个性化结果、地区或订阅限制、限流及远端增删。三个账号平台的完整音频交付仍待实现。[平台账号](../providers/platform-login.md)
- [ ] 复核[旧公网测试](../../tests/e2e/online_live_test.go)对未登录查询的预期，再以实际授权会话验收。
- [ ] Bilibili 的匿名资料与音频首块已有抽测。真实多页收藏夹、音频歌单及浏览器整曲播放仍待复验。私有内容和可选账号能力属于后续范围。[Bilibili 来源](../providers/bilibili.md)
- [ ] 对已接入的在线资料插件，逐来源验证候选、字段选用、人工锁、内容授权及上游失败时的结果保留。[在线资料插件](../metadata/online-scrapers.md)

## 音频与客户端

- [ ] 使用真实扬声器或耳机核对原流、处理流和 NCM 的曲目、声道、音量、定位与连续切歌。
- [ ] 在 Linux 浏览器、Firefox、Safari 等目标环境验证首声、暂停与恢复、快速定位、切歌及授权失效。补齐不同格式、声道布局、NCM 变体及 DSP 组合。
- [ ] 为各输出档案记录定位容差，测试前导静音和编码延迟；现有 MP3 场景容差为 100 ms。跨源续播还需双方当前资产的时间轴证据。
- [ ] 桌面客户端的原生播放、启动归属、多客户端租约、崩溃回收和升级需与实际客户端联合验收。

## 文件系统与曲库

- [ ] 在实体 NAS 验证断线、重挂、慢盘、部分权限、挂载替换及目录通知丢失。原生 NFS/SMB 直连待实现后单独验证。[NAS 设计](../design/nas-providers.md)
- [ ] 在目标文件系统测试稳定读取、SQLite 锁，以及 Linux 挂载或 Windows junction 并发置换。Linux 实机补验不限深度、隐藏项、`.nomedia`、通知与范围对账。
- [ ] 大库验证长时间扫描、播放、摘要及快照一小时上限。另需排查 Worker 分页的一次 10 秒超时，复现时记录请求阶段和负载。
- [ ] 使用经授权的真实音乐比较重编码、剪辑、混音和不同演绎。合成纯音已有碰撞样本，候选均须人工审核。
- [ ] 在目标介质演练断电恢复。原件写回范围限于已声明的 Windows 本地 NTFS 普通 FLAC，定制 SACL 与其他介质待验。

## 部署与长期运行

- [ ] 在原生 Linux、ARM64、macOS 及目标发行版验证当前制品。复验外部 SQLite/DSP、插件停用重启以及目标平台插件的失败路径。
- [ ] 在独立干净机器上完成当前制品安装、工具配置、扫描、原流及处理播放、备份恢复和退出。
- [ ] 使用真实 Docker/Compose 与 Nginx/TLS 验证只读挂载、持久数据、健康检查、Cookie、Origin、首帧 CSRF、WS 重连和 HTTP Range。
- [ ] 验证插件/SDK 升级及备份恢复后的账号会话。备份含凭据密文与保护密钥，按凭据管理。
- [ ] 长期观测慢消费者、并行后台任务与句柄数量，复核 Windows 短测中尚未归因的 65 个句柄。检查完整处理缓存的闲置回收、24 小时上限、重启和配额压力。
