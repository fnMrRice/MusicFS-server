# S-P7-05 个人歌单 HTTP 与实际服务验收

日期：2026-10-10。范围是本人个人歌单API、SQLite聚合规则、完整出处、隐藏确认和生产组合。合成本地WAV及独立合成在线Worker只用于验证MusicFS行为，没有平台凭据、外网请求、私人歌单、商业音频下载或远端写回。

## HTTP与契约

新增本人歌单创建/读取/列表/整体编辑、重建收据、固定快照分页、隐藏规则读取/新增/更新和序号审计。规则、隐藏和快照分别修订；修改均要求会话、Origin、CSRF、明确预期修订与幂等键。重建响应只返回修订、依赖和确认状态，不直接展开全部条目；分页仍保留每项完整provenance及隐藏标记。

`tests/contract/api/playlists_http_test.go` 使用实际HTTP和SQLite，发布三个本人来源和一个其他owner来源后验证：

- 创建保留本地顺序及重复出现；同键重放身份保持，缺键/必需字段拒绝；缺登录、缺CSRF和错误Origin不能修改。
- 嵌套歌单聚合保留两层bindingPath、原歌单/出现身份；同一来源去重后仍保留全部出处。循环、其他owner来源、其他owner歌单/隐藏/快照/审计、错误分页参数明确拒绝。
- 默认allSources隐藏保留原SourceRef；之后人工关联扩大集合时，新成员可见且needsConfirmation。显式确认后才扩大；解除关联后仍以原锚点限制，不把意图扩散到其他结果。
- 删除子绑定仅移除它的贡献，剩余绑定保持，隐藏意图独立保存；旧快照和旧重建幂等结果不随新规则改写，旧hideRevision冲突。
- 公开结果没有owner、私有路径和其他用户来源编号。输入SourceRef恰一种来源、remote绑定不能追加inline条目、revision/confirm必填等分别有有效/无效Schema样本。

新路由集合、HTTP/插件全模型编译和OpenAPI引用/安全结构检查通过。P706/P8后续契约不包含在本步骤冻结版本中。

## 真实服务与播放回归

`TestPlaylistsActualServerLocalRemoteHiddenMatchingAndRestart` 读取真实YAML，启动正式Server、实际Local Files Worker与独立合成网易Worker。临时目录三个WAV由已有合成markers.wav复制，源字节已知；远端固定Transport返回包含一次重复曲目的公开歌单形状，经过生产导入和同步API持久发布。

测试把本地子歌单、独立本地追加和远程歌单按顺序组合，得到5个聚合条目；本地重复与远程重复均保留两条provenance。随后通过真实HTTP隐藏原锚点、人工关联、重建检查待确认、明确确认、解除关联、删除子绑定并重建，逐阶段断言可见数量、来源代表、确认状态和历史快照身份。

停服并禁用在线实例，以同一数据目录重启后规则修订、隐藏修订、隐藏规则编号/启用状态和旧远程聚合历史保留。对已隐藏来源仍使用原播放API创建WAV会话，验证实际Range响应与合成原始字节一致并成功停止；三份文件最终逐字节保持不变。隐藏规则只影响歌单可见性，不改变播放授权或写入原件。

首次普通E2E在播放契约断言处误用不存在的Schema名称，前面的聚合/确认/重启已通过；改为既有Playback名称后，完整E2E及播放回归重新通过race。没有修改生产播放行为或放宽Schema。
