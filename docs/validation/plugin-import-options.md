# 插件导入选项验证

本记录对应 2026-10-10 的开发基线。Local Files 插件提供配置说明、受限 JSON Schema、默认值和不可用选项；YAML 与 HTTP 共用声明。覆盖范围为递归、深度、选中授权根和显式拒绝尚未实现的歌词导入。没有动态启停、歌词处理或导入表单界面。

## Windows 定向结果

使用当前仓库依赖执行 `go test -mod=readonly`：jsonschema/v6 6.0.3、yaml/v3 3.0.5、x/sys 0.49.0、SQLite 驱动 1.60.1；本步没有修改依赖文件。

| `tests/unit/config` | 3.090 秒，通过；逐层归一、矛盾深度、null/未知字段、YAML 严格类型、不可用歌词与配置快照指针隔离 |
| `tests/contract/plugins` | 0.311 秒，通过；真实官方声明、插件规则实际执行、外部引用/未知关键字/过大说明/过深声明拒绝 |
| `tests/contract/api` | 2.647 秒，通过；HTTP/插件 Schema、实际序列化 DTO 与正反样本 |
| `TestYAMLPluginImportOptionsHTTPAndScopedLibrary` | 最终单项 2.15 秒、包 2.735 秒，通过；真实 YAML Server 与 Local Files Worker |

真实服务用项目 CC0 合成 WAV 构造两个根和三层文件。实例 `recursive:false` 扫描根本层；请求重新开启递归且省略深度时返回有效深度 64。移除子目录文件后先做浅层扫描，深层曲目与另一个根均保留；随后只扫描选定根到深度 1，该范围内消失的文件才标记 missing，更深文件与另一根仍可用。请求覆盖同时验证旧 schema 修订、未授权根、重复根、矛盾深度、null、未知键和歌词 true 的明确失败；相同有效计划重放同任务，改变参数的同幂等键返回冲突。

Provider 实际响应只返回根编号与显示名，测试检查无授权路径、程序路径、引导令牌、rootIdentity、configRevision 或 stateDir。启动时还检查实例默认值满足已验证 Worker 的实际声明。代码不能仅靠界面开关过滤，真实遍历与持久发布的更多范围/代次/硬链接检查由对应集成测试覆盖；全量、race 与 Linux 联合结果由主验收记录补充，不能从本表推断。

## Web 契约适配

Web 两个测试准备器改为先读取 Provider 的 schemaRevision 和授权 rootIds，再提交 `options:{}`。产品源码没有扫描入口，本次未改 UI。该仓库本地提交为“test: 从插件声明构造扫描请求”；此处引用稳定标题，避免后续补签改变提交号。

`npm run build` 通过。Windows Edge 定向运行 3 项，全部通过，总计约 1.3 分钟：NCM MP3 解密/Range/浏览器播放 4.5 秒，登录/CSRF/扫描/固定分页/刷新会话/退出 34.9 秒，目录离线保留已发布库并退出卸载媒体 1.6 秒。测试使用隔离服务与项目合成音频，未访问用户音乐或凭据；没有再次执行完整浏览器套件。

以上证明真实媒体事件与解码数据，不代替人工听音；Linux 浏览器、macOS、ARM 与 NAS 实机不在本轮范围。已有旧阶段截图和数字保留其原验收范围，本轮不覆盖历史记录。

## 冻结版本联合检查

主代理从仅包含本步骤的暂存树导出独立源码，排除正在开发的指纹/媒体文件模块后复验。Windows `scripts/check.ps1 -Race` 全部通过，包含格式、vet、覆盖率、完整测试和竞争检查；正常 E2E 72.491 秒、插件集成 59.878 秒、存储 34.069 秒，race 对应 91.964、70.219、45.499 秒。Linux 原生 vet 与全量测试通过，E2E 177.017 秒、插件 135.616 秒、存储 4.069 秒；核心识别/存储/API/E2E race 全部通过，E2E 138.536 秒。Linux 使用原生临时目录、当前固定 Go 依赖及真实 FFmpeg/ffprobe。

另有 Linux 真实 Worker 范围/硬链接/游标/重启/快照期限 race 定向验证，43.841 秒通过。完整回归首次发现 `scripts/scan.ps1` 仍发送旧请求；修复后原失败 E2E 单项通过，并已包含在上述最终冻结版本。手动脚本现从 Provider 声明构造请求，支持选根、递归和深度参数；该变更不是服务端旧请求兼容层。

数据库迁移 007 明确清理没有完整计划的旧扫描任务及对应扫描幂等缓存，不构造兼容计划，保留曲库、资产、证据、哈希任务和其他幂等记录。含多种旧任务状态的真实旧 schema 升级 race 测试通过，并验证迁移前备份与新任务可执行。
